## Description

A complete implementation of Domain-Driven Design with SOLID principles and Clean Architecture in C#/.NET 8. Demonstrates layered architecture, domain modeling, repository patterns, and dependency inversion.

## Architecture

Clean Architecture (DDD): Presentation Layer → Application Layer → Domain Layer → Infrastructure Layer

## Quick Start

### Prerequisites

.NET 8 SDK, Visual Studio 2022 / VS Code with C# Dev Kit

### Installation

```bash
# Clone
git clone https://github.com/J1u2a3n8/mc-nuts-ddd-solid.git
cd mc-nuts-ddd-solid

dotnet restore
# dotnet build
```

### Usage

```bash
dotnet run --project src/MCNutsAPI
```

## Testing

```bash
dotnet test
```
